updated: 2026-10-06T19:08

- (decision) Scope: two screens, desktop-first. (1) Open Roles: searchable list with empty state. (2) Job Application: job detail plus apply form.
- (decision) Token set is closed. Only: color-surface #ffffff, color-ink #1a1d21, color-muted #6b7280, color-accent #2563eb, color-danger #dc2626; space-1 4px, space-2 8px, space-3 16px, space-4 32px; radius 6px; font-sans system-ui,sans-serif. No new tokens may be added.
- (override) User-supplied token set overrides the CLAUDE.md HireFlow tokens (Inter, #1D4ED8, #B91C1C, border/background/tint tokens) for this spec. User was asked and chose the default (their tokens).
- (decision) No design system or UI library yet.
- (decision) Every state must be specified, not just the happy path: empty list, inline validation errors, submitting, success, error.
- (decision) Working mode: fast path. Draft both spines with [ASSUMPTION] tags and skip creative tools until key-screen mocks.
- (decision) Type sizes come only from spacing tokens: body 16px (space-3), page title 32px (space-4). Below that, hierarchy uses font weight (400/600/700) and color (ink vs muted). No typography-size tokens are added.
- (decision) Apply form (lean): full name (required), email (required), phone (optional), CV upload (required, PDF/DOCX, max 5MB), cover note (optional).
- (decision) Stakes: public, consumer-facing careers site. WCAG 2.2 AA is the floor.
- (assumption) Protagonist for journeys: Priya, a backend developer applying to Senior .NET Engineer at Northgate Labs on her laptop during a lunch break. Fast-path placeholder; the user has not narrated one.
- (decision) Contrast verified: muted/surface 4.8:1, accent/surface 5.2:1, danger/surface 4.8:1, surface on accent 5.2:1, all AA. Muted may be used as the 1px input/card border (non-text needs 3:1).
- (decision) Since there are no hover, tint or border tokens, states use structure rather than new colours: hover means underline or border colour moving muted to accent; focus is a 2px accent outline with offset; error is a danger border plus danger text and an icon; disabled is opacity, never a new grey.
- (decision) Disabled/locked: no opacity. Locked inputs are readonly with unchanged visuals; the submit button stays full colour and its label 'Sending your application…' carries the state. No new token.
- (event) Key-screen mocks rendered: .working/key-open-roles.html and .working/key-job-application.html (incl. 360px error-state frame). Token greps clean. The earlier 'disabled is opacity' entry is superseded by the no-opacity decision.
